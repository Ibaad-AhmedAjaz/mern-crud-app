# MERN CRUD Application

A full-stack CRUD application built using the MERN stack. This project demonstrates basic Create, Read, Update, and Delete operations with a React frontend and Node.js/Express backend connected to MongoDB.

## 🚀 Live Demo
Frontend: http://mern-frontend-ibaad.s3-website.eu-north-1.amazonaws.com/

Backend: http://13.51.38.243:8000/api/users

## 🛠️ Tech Stack
- Frontend: React.js, JavaScript, HTML, CSS
- Backend: Node.js, Express.js
- Database: MongoDB
- APIs: REST APIs
- Deployment: AWS (S3 + EC2)

## ✨ Features
- Create, update, delete, and view records
- REST API integration between frontend and backend
- Responsive UI using React
- Real-time data updates
- Error handling for API requests

## 📁 Project Structure
- Frontend built using React.js
- Backend built using Express.js and Node.js
- MongoDB used for database storage

## ⚙️ Setup Instructions
1. Clone the repository
2. Install dependencies in both frontend and backend
3. Configure MongoDB connection string
4. Run backend server
5. Run frontend React app

## 📌 Note
This project is deployed using AWS services and demonstrates full-stack development with API integration and cloud deployment.
